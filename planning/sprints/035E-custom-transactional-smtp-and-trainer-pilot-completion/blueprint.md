## Rollback

Before SMTP mutation, establish executable rollback:

1. Restore the exact prior Supabase SMTP configuration or disable custom SMTP to the captured prior state.
2. Restore/remove only 035E-owned DNS records using captured RRsets.
3. Preserve the current OTP template; do not reconstruct a Magic Link template.
4. Restore the OTP-compatible forward deployment only if an in-scope application release must be rolled back.
5. Reverify five aliases, Site URL/callbacks, public/protected route safety and provider settings.
6. Clean exact-owned state Auth-last and record the failure without participant acceptance.
