# Sprint 001 - Existing Project Feature Or Fix

## Goal

Define the first useful sprint for the existing Precision Performance project.

## Scope

- Review current planning state.
- Use reference material under `references/` as source context.
- Identify the smallest useful outcome for Sprint 001.
- Set a workflow profile: fast, standard, or strict.
- Define the approved file set before Builder implementation.

## Out of Scope

- Broad rewrites.
- Unrelated refactors.
- New platform migration.
- Production deployment changes.
- Payment, auth, team, or data-model changes unless explicitly approved in this sprint.
