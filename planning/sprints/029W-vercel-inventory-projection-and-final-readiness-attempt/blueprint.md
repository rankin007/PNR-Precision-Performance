| Provider transfer/row gate fails | No retry; remove exact safe owned resources | Park clean only with zero residue |
| Deploy response fails | No retry; reconcile via owned hostname then inspect | Clean only after exact deletion/final zero; otherwise material |
| Candidate/routing/readiness/expiry fails | Stop downstream work; compensate exact owned non-routing resources | Park clean only with safe terminal state |
| Alias movement, competing deployment, ownership or cleanup ambiguity | Stop; no alias command | Material; preserve safest state and request fresh authority |
| Supporting tool fails but equal/stronger proof exists | Diagnose once and substitute | Continue and record |
