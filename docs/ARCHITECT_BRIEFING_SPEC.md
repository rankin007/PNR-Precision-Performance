# Architect Briefing Spec

`planning/ARCHITECT_BRIEFING.md` is the Builder's sprint-close snapshot for the next Architect session.

It should be short, current, and safe to read quickly. It must not contain source code, secrets, API keys, passwords, tokens, or private credentials.

Recommended sections:

1. `## Where things stand` - two to four plain-English sentences.
2. `## Current status` - sprint state and whether the work is complete.
3. `## Since last sprint` - what changed.
4. `## Architecture / file map` - relevant files and responsibilities, no code dumps.
5. `## Decisions` - durable choices made during the sprint.
6. `## Risks / watch-items` - issues to keep visible.
7. `## Open questions for the Architect` - unresolved product or scope choices.
8. `## Validation / test status` - what was run and what was not.
9. `## Recommended next Architect action` - the next planning move.
